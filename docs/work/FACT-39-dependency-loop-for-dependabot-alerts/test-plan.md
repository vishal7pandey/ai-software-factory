# FACT-39 — Test plan: Dependency loop for Dependabot alerts and PRs

Status: plan-approved · Risk: medium · Jira: FACT-39

Test framework and conventions found: pytest, tests in `tests/` named `test_<area>.py`, `tmp_path` fixtures, autouse isolation in `tests/conftest.py` (no registry, no project commands, and `harden._run_gh` answers "gh unusable" so the suite cannot reach the network); run everything with `uv run python -m pytest -q` (`pytest.exe` is blocked on this machine), then `uv run ruff check . && uv run ruff format --check .`, `uv run python -m swfactory.cli lint` and `... sync --check .`. New tests: `tests/test_dependencies.py` (contract tests on the real policy, skill and routing text; summary tests with a stubbed `gh_api`; status and doctor wiring; the scripted triage walkthrough; a sync test) and `tests/test_dependabot_template.py` (generator, manifest, lint, adopt/sync). The walkthrough takes its `gh` commands out of the real skill text and its fake `gh` rejects any other command or `--admin`, like the FACT-34 helper.

## Regression risk

`work.cmd_status` now makes read-only GitHub calls for a project with a github.com remote: the autouse `no_real_gh` fixture keeps every existing test offline, and projects in `test_work.py` have no remote so their output is unchanged. `doctor` gains `deps:` lines: `test_doctor.py` assertions on project checks must stay green. A new `create` file changes the counts in adopt/sync tests that list written files (`test_install.py`, `test_findings.py::sync`, `test_sonar.py`); they must be updated only where they count files. `AGENTS.block.md`, `autonomy.md`, `factory-workflow` and `factory-findings` change text that `test_findings.py` pins (`findings` in the block, the closure sentences): those tests must stay green unchanged. `test_integration.py::test_factory_repo_is_in_sync_with_its_kit` fails until `factory sync .` is run.

AC4 is verified by the two apply work items against the real repositories, not by this item's automated tests (see Manual checks). Whether an agent obeys the policy text is not testable here (the drill of FACT-37 covers that); the rules are pinned as text and as functions.
