Status: in-review · Risk: medium · Jira: FACT-39

## Regression risk

`work.cmd_status` now makes read-only GitHub calls for a project with a github.com remote: the autouse `no_real_gh` fixture keeps every existing test offline, and projects in `test_work.py` have no remote so their output is unchanged. `doctor` gains `deps:` lines: `test_doctor.py` assertions on project checks must stay green. A new `create` file changes the counts in adopt/sync tests that list written files (`test_install.py`, `test_findings.py::sync`, `test_sonar.py`); they must be updated only where they count files. `AGENTS.block.md`, `autonomy.md`, `factory-workflow` and `factory-findings` change text that `test_findings.py` pins (`findings` in the block, the closure sentences): those tests must stay green unchanged. `test_integration.py::test_factory_repo_is_in_sync_with_its_kit` fails until `factory sync .` is run.
